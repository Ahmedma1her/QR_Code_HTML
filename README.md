# Ahmed Maher Salama — Digital Resume

A responsive, mobile-friendly personal resume page for Ahmed Maher Salama, built as a single self-contained HTML file.

## Overview

This project presents a professional online CV with:

- Personal profile and professional title
- GitHub and LinkedIn links
- An interactive view of the LawBridge graduation project infographic
- Work experience and project highlights
- Technical skills
- Education and certifications
- Light and dark color modes
- Mobile-safe responsive layouts

## Features

- **Responsive design:** Fits desktop, tablet, and mobile screens.
- **Automatic dark mode:** Uses the device preference unless a theme is selected.
- **Accessible interactions:** Keyboard focus states, semantic sections, and an Escape-key-closeable enlarged image viewer.
- **Self-contained assets:** The profile photo and LawBridge infographic are embedded directly in `index.html`.
- **External profile links:** Direct links to GitHub and LinkedIn.
- **No build step:** Open the HTML file directly in any modern browser.

## Technology

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Getting Started

### Prerequisites

- A modern web browser
- Internet access for Google Fonts

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ahmedma1her/QR_Code_HTML.git
   ```

2. Open the project directory:

   ```bash
   cd QR_Code_HTML
   ```

3. Open `index.html` in your browser.
